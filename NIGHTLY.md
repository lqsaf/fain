# Nightly queue

The nightly agent takes the first unchecked task, implements it, runs the checks,
and ticks the box. Keep tasks small and self-contained, with acceptance criteria.

Replace the examples below with real tasks.

- [ ] **Example: add a smoke test** — cover the empty-input path in
  `src/parse.test.ts`. Done when `npm test` is green.
- [ ] **Example: fix a TODO** — replace the TODO in `src/foo.ts` with a real
  implementation and a test.
