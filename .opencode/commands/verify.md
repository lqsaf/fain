Запусти `npm run verify` и разбери результат.

Если проверки зелёные — коротко перечисли, что проверено, и остановись.

Если есть падения:

1. Сгруппируй ошибки по проверке (`js.syntax`, `i18n.parity`, `storage.keys`, `html.contract`, `css.integrity`, `queue.protocol`, ...).
2. Для каждой ошибки назови файл, причину и минимальное исправление.
3. Исправь только причины падений, не отключая и не ослабляя проверки.
4. Повтори `npm run verify` до зелёного результата.

Не коммить и не пушь.
