1. `npm run fa:queue` — очередь задач.
2. `npm run fa:status` — статистика и последний запуск, если есть `fa/logs/latest.json`.
3. Отметь: какие задачи `[ ]` готовы, какие `[!]` заблокированы и почему, какие ждут `needs:`.

Ничего не меняй. Ответь таблицей и одним абзацем о том, что требует внимания человека.
