# Repository instructions

- One task per run: the first unchecked item in `NIGHTLY.md`.
- Keep changes focused; no drive-by refactors.
- Run the test and lint commands listed in `NIGHTLY.md` or `package.json` before
  finishing.
- Never touch `.env` files, credentials, or secrets.
- Never push, force-push, merge, or change branch protection. The automation
  wrapper owns Git.
- Update `NIGHTLY.md` (tick the box, add a one-line note) as part of the change.
