# Execution — где и в каких рамках работает FA

Слой отвечает на вопрос: **где исполняется агент и что физически не даёт ему выйти за рамки**. Ограничения живут в коде и конфигурации раннера, а не в промпте.

## Среда

- GitHub Actions, `ubuntu-latest`, Node.js 22, OpenCode CLI запинен по версии.
- Один job = ровно одна задача, бюджет запуска `FA_RUN_BUDGET_MIN=90`, жёсткий потолок job — 90 мин.
- Watchdog (`schedule: */30 * * * *`) поднимает следующий запуск, если очередь не пуста.
- `concurrency: fa-loop` не даёт двум запускам работать одновременно.
- Локальный запуск — тот же `scripts/fa/loop.mjs`, но только с `--force-local` и на чистом дереве.
- Модели и порядок fallback задаются в `scripts/fa/models.mjs`; `FA_MODELS` задаёт общий список, а `FA_PLANNER_MODEL`, `FA_EXECUTOR_MODEL`, `FA_REPAIR_MODEL`, `FA_REVIEWER_MODEL` — роль-приоритеты.
- Стандартный список не полагается на неподтверждённый бесплатный каталог OpenCode или прямой Anthropic-ключ; в нём используются Gemini и XEROSHARC, NVIDIA NIM остаётся опциональным.
- До пяти ключей Gemini (`GEMINI_API_KEY`, `GEMINI_API_KEY_2` … `_5`) могут ротироваться после quota/rate-limit; значения секретов не выводятся в логи.
- OpenRouter ERNIE Flash Preview доступна для planner/reviewer, а не для реализации; одношаговый профиль без инструментов и persistent UTC-счётчик ограничивают её двумя API-запросами в сутки по умолчанию (`FA_OPENROUTER_ERNIE_DAILY_LIMIT`).

## Лимиты (все в коде)

| Лимит | Где | По умолчанию |
| --- | --- | --- |
| Время на задачу | `FA_TASK_TIMEOUT_MIN` | 25 мин |
| Бюджет запуска | `FA_RUN_BUDGET_MIN` | 90 мин |
| Задач за запуск | — | 1 (жёстко) |
| Попыток на задачу | `FA_MAX_ATTEMPTS` | 2 |
| Шагов агента | `.opencode/agents/fa.md` → `steps` | 60 |
| Токен-бюджет запуска | `FA_TOKEN_BUDGET` | 2 000 000 |
| Инфра-провалов подряд | `FA_MAX_INFRA_FAILURES` | 3 |
| Размер диффа | `scripts/fa/config.mjs` + `scripts/fa/loop.mjs` | 25 файлов / 2500 добавленных и удалённых строк |

Почему так: в видео разобран кейс, где агент 100 раз вызвал один и тот же инструмент, а лимит был только в промпте. Промпт не исполняется — исполняется код.

Перед каждой фазой роутер резервирует расчётный бюджет; фактическое потребление заменяет резерв, если модель сообщает usage. После исчерпания лимита новые вызовы не запускаются. Если провайдер не вернул usage, учитывается полный резерв фазы, поэтому защита консервативна; один уже начатый вызов может превысить оценку.

## Изоляция

- Агент работает только внутри репозитория: `external_directory` запрещён.
- Нет доступа к `.env`, `.dev.vars`, `~/.ssh`, `~/.aws`, `~/.config/gh`.
- Нет `webfetch`/`websearch`: входные данные недоверенные, контекст должен быть воспроизводимым.
- Нет установки пакетов, деплоя, публикации, git push/commit.
- Секреты провайдеров живут в GitHub Secrets и доступны только процессу `opencode`; в файлы и логи не попадают.
- Агент не может править собственный harness: список защищённых путей в `scripts/fa/policy.mjs`, проверка — в оркестраторе и `verify --protected`.

## Отказы

| Отказ | Поведение |
| --- | --- |
| Таймаут задачи | процесс убивается по группе, дерево откатывается, попытка +1 |
| Ненулевой exit OpenCode | то же; текст ошибки в лог, без секретов |
| Квота/429/401 провайдера | переключение на следующую модель в том же шаге, попытка задачи не тратится |
| Все модели исчерпаны | запуск завершается, задача остаётся `[ ]` до следующего watchdog |
| Нет изменений после «DONE» | считается провалом (state hole), попытка +1 |
| Изменены защищённые файлы | провал, откат, попытка +1 |
| 3 инфра-провала подряд | запуск останавливается, создаётся issue |
| Упал `verify` | откат, попытка +1; после лимита — `[!]` и issue |
| Непрофильная задача | UI smoke пропускается, чтобы несвязанный UI-дефект не блокировал её проверки |
| Нет задач | запуск завершается штатно; watchdog не поднимает пустой запуск |
| PR закрыт без merge | запуск останавливается: решение человека |

## Локальный запуск

```bash
export GEMINI_API_KEY="..."      # не коммитить
export XEROSHARC_API_KEY="..."   # не коммитить
# опционально: export FA_MODELS="google/gemini-3.1-flash-lite,xerosharc/claude-haiku-5-5"
npm run fa:preflight
npm run fa
```

Требования: Node 22+, OpenCode в `PATH`, чистый git worktree, ключ хотя бы одного провайдера. Локальный запуск не пушит в main: он работает с той же веткой `fa/work` и тем же PR-контрактом.
